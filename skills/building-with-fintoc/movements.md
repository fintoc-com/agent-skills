# Movements — index (Data Aggregation, Chile only)

Read-only access to a user's bank transaction history via Links. Marketed as "Conexiones". The user authenticates their bank through Fintoc, and you exchange a token for ongoing read access.

See [fundamentals.md](fundamentals.md) for pagination — movement lists can be long, so never fetch a single page.
