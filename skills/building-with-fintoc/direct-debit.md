# Direct Debit — index (Chile only)

Recurring charges via PAC (débito directo) on an authorized subscription. The user authorizes the mandate once; you then charge on a schedule. Marketed alongside "Pagos Recurrentes" / "motor de cobro".

For card-style recurring payments (not bank débito directo), see [payments.md](payments.md) instead. See [webhooks.md](webhooks.md) to track charge outcomes asynchronously.
